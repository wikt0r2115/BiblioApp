# BiblioApp v1.0.0

Pierwsze odtwarzalne wydanie REST API biblioteki.

- Wypożyczenie, zwrot i archiwizacja zachowują spójność także przy równoczesnych żądaniach. PostgreSQL ogranicza liczbę aktywnych wypożyczeń książki do jednego.
- Testy obejmują pełny przepływ API na PostgreSQL z migracjami Flyway, wyszukiwanie i paginację.
- Demo Docker zawiera dane przykładowe, skrypt smoke, instrukcję restartu oraz kopii i odtworzenia danych.
- Kontrakt endpointów i błędów znajduje się w `openapi.yaml`.

Obraz: `ghcr.io/wikt0r2115/biblioapp:v1.0.0`. Dla pełnej identyfikowalności dostępny jest również tag `sha-<pełny SHA commita>`. Wskazówki uruchomienia są w README.
